# arduino-temp-humi-reader
DHT11 Sensor reads current temperature and humidity and results are displayed on an LCD1602 Module

-Components-
1. Elegoo Arduino Uno R3 Microcontroller
2. Temperature Sensor with 3-pin header
3. LCD1602 Screen Module
4. Solderless Breadboard
5. Jumper Wires

-Libraries used-
1. LiquidCrystal by Arduino, Adafruit
2. DHT Sensor library by Adafruit
